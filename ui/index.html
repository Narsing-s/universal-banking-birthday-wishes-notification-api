Birthday Wishes Notification

Operational dashboard for the Universal Banking Birthday Wishes Notification API. The existing MuleSoft integration remains unchanged; this UI is a separate presentation layer.

Integration flow

1

Schedule

Mule Scheduler starts the birthday processing flow.

2

Find customers

Birthday candidates are read from the configured Snowflake table.

3

Build message

Customer and bank information is transformed into the email template.

4

Send wishes

The configured SMTP service delivers the birthday notification.

5

Mark processed

The customer notification timestamp is updated in Snowflake.
